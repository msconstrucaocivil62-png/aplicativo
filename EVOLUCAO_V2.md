# Conecta Pro — Evolução V2

Esta versão mantém o nome e a identidade visual do aplicativo e acrescenta uma Central de Negociação integrada.

## Recursos adicionados

- Profissionais podem enviar orçamento com valor, prazo e descrição do que está incluso.
- Clientes podem comparar propostas e contratar um profissional dentro do aplicativo.
- Ao aceitar uma proposta, o pedido muda para “em andamento” e fica vinculado ao profissional escolhido.
- Chat por pedido com histórico persistido no banco local.
- Dados de propostas e mensagens disponíveis na API.
- Correção da listagem “Meus pedidos”: o cliente agora vê apenas os próprios pedidos.

## Teste rápido

1. Entre como cliente Mariana e abra a Central de Negociação.
2. Selecione o pedido de tomadas 220 V.
3. Compare as propostas e clique em Contratar.
4. Use o chat para enviar uma mensagem.
5. Troque para o perfil profissional Carlos para enviar novas propostas e responder no chat.

Esta continua sendo uma versão de homologação local. Publicação real exige banco de produção, autenticação segura, armazenamento de arquivos, notificações push e integração de pagamento em ambiente de produção.
